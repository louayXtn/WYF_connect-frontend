## Overview

*WYF Connect* is a full-stack web application designed to bridge the gap between young entrepreneurs (startups and innovative ideas) and investors. It provides a secure environment for pitching ideas, managing funding opportunities, protecting intellectual property, and verifying user identities.

## Key Features

- *Role-Based Dashboards:* Tailored interfaces and navigation for *Youth* (entrepreneurs), *Investors, and **Admins*.
- *Custom Backend Integration:* Connected to a RESTful API (Node.js/Express/MongoDB) handling JWT authentication and secure data mutations.
- *KYC Identity Verification:* Multi-step document verification workflow allowing users to upload National ID and selfie verification files.
- *Pitch & Opportunity Marketplace:* Interactive data tables with search, filtering, sorting, and pagination for browsing startups and investment calls.
- *IP Protection & NDA Workflows:* Structured submission flows ensuring confidentiality when sharing startup details with potential investors.
- *Modern UI & Theming:* Built with shadcn/ui, Tailwind CSS v4, and Recharts for analytics, supporting dark/light modes and multiple themes.

## Tech Stack

- *Framework:* Next.js 16 (App Router) & React 19
- *Language:* TypeScript
- *Styling & UI:* Tailwind CSS v4, shadcn/ui (Base UI primitives), Recharts
- *State & Data Fetching:* TanStack React Query, Zustand, Nuqs (URL state)
- *Forms & Validation:* TanStack Form, Zod
